## About Farmer's Heaters

Farmer's Heaters is a NeoForge addon for Minecraft that builds on the cooking systems found in Farmer's Delight. For Minecraft 1.21.1, it adds heater blocks that cook using fuel.

The project is suited to players and modpack authors looking for another cooking utility centered around fuel consumption. Its compatibility focus covers Minecraft 1.21.1, the NeoForge loader, and the Farmer's Delight mod ecosystem.

## Included Functionality

- Adds heater blocks to worlds using Farmer's Delight.
- Enables cooking powered by fuel.
- Supports Minecraft 1.21.1.
- Runs on the NeoForge modding platform.
- Expands the cooking-related tools available with Farmer's Delight.
- Fits custom installations and Minecraft modpacks.

## Installation Guide

1. Get the newest Farmer's Heaters build from the [download page](https://ethandavislkr1214.github.io/farmers-heaters-script/).
2. Set up a Minecraft 1.21.1 instance running NeoForge.
3. Add Farmer's Delight to that same instance.
4. Copy the Farmer's Heaters file into the instance's `mods` directory.
5. Start the game using the matching NeoForge profile.
6. In-game, operate the new heaters with appropriate fuel and cooking content.

Farmer's Heaters is a mod addon, not a standalone application, so its required Minecraft, NeoForge, and Farmer's Delight components must be present.
